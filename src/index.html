Overprint Preview

Mirrors Acrobat's Output Preview "Simulate Overprinting". Off shows the naive on-screen composite (overprinted objects knock out what's beneath). On shows what will actually happen on an overprint-aware output device.

Separations

    Toggle plates to inspect trapping — e.g. check whether black text is set to overprint (K only, colors underneath still present) versus knockout (a white gap in the other plates).

    Mode

    Page Rotation

    Sets the page's /Rotate entry — the same thing Acrobat's "Rotate Pages" changes. Applies immediately, and the preview + box overlay re-render to match.

    Page Boxes

    Values are in PDF points (1 pt = 1⁄72 in), in the page's own unrotated coordinate space — the same numbers Acrobat's Crop Pages / Document Properties show. Edits apply immediately and are saved to the file (a one-time .bak backup is made on first edit).
