Colour Profiles

  • Open a PDF to see its colour profiles.

The ICC profiles embedded in the PDF. The output intent is the press condition the file was made for (e.g. Coated FOGRA39 for PDF/X). Other profiles describe the colours of images and artwork. Colours with no profile are plain CMYK, RGB or grey. Tick Preview with to preview the page as it would print with the chosen CMYK profile.

Overprint Preview

%

Off: the page is drawn exactly as the PDF describes it — vectors and text as vectors (sharp at any zoom), images at their own pixels. On: shows what an overprint-aware press will produce; ink mixing has to be calculated per pixel, so this view (and Separations) is drawn at screen resolution.

Separations

  • Open a PDF to see its separations.

Hover over the page to read the ink at the cursor. Untick plates to inspect trapping — e.g. whether black text overprints (colours still underneath) or knocks out (a white gap in the other plates).

Fonts

  • Open a PDF to see its fonts.

Every font should be embedded for print. A font that isn't gets swapped for another on the printer, so text can change or reflow. Converting text to outlines removes the need for fonts.

Recolour

Select a shape, text or logo with the Select tool (V) to change its colour.

Current fill
Current stroke

Recolours the selected objects on this page in CMYK. To change a colour everywhere it's used, see Global Colour Change.

Selected Objects

Turn on the Select tool (V) and click a shape, text or image on the page.

To change the colour of everything selected, use the Recolour panel above.

Convert to spot colour

Drag the selection to move it; arrow keys nudge it 0.5 mm (Shift: 5 mm). These edits apply to this page only. A placed graphic, such as a logo placed in InDesign, moves as one piece.

Global Colour Change

Select an object with the Select tool (V) to change every object that shares its colour.

Replace with

Finds every object whose colour matches the first selected object, on this page or all pages (Apply edits to), and gives them the new CMYK colour. Point at this panel to see the matches outlined in gold.
